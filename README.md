# 🪨 Rage Platformer — Unreal Engine 5

**Rage Platformer** is a 2D platformer game developed in **Unreal Engine 5** using its **Blueprint system**. The game features **6 carefully designed levels** with increasing difficulty, challenging players’ precision, timing, and resilience. The ultimate goal? **Reach the diamond at the end** — if you can.

---

## 🎮 Gameplay Overview

- **Genre**: 2D Platformer (Rage Game)
- **Engine**: Unreal Engine 5 (Blueprints only)
- **Levels**: 6 progressively difficult stages
- **Objective**: Reach the diamond to complete the game
- **Challenge**: Fast reflexes, pixel-perfect jumps, and steady patience required!

---

## 🧠 Features

- Built entirely with **UE5 Blueprints** (no C++ involved)
- Smooth player movement and responsive controls
- Custom level design with distinct traps and obstacles
- Checkpoints (when I felt generous)
- Clean and minimal UI for an immersive experience

---

## 🛠️ Tech Stack

- **Game Engine**: Unreal Engine 5
- **Programming**: Visual Scripting (Blueprints)
- **Design**: UE5 Level Editor, custom sprites and assets
